# irc chatbot
This is an irc chatbot for csc482:Natural Language processing. Tested on unix3.csc.calpoly.edu.

## setup
Run `bash setup.sh` to set up the venv. The code requires python3.9+. The script will run `python3.9 -m venv venv`. Feel free to change the
version if you happen to have another version of python installed that
is 3.9+.

## use
Run `source venv/bin/activate`,

then run `python irc_source.py`
